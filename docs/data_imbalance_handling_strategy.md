# ⚖️ 데이터 불균형 해결을 위한 하이브리드 샘플링 전략 (Hybrid Sampling Strategy)

본 문서는 GaitRec 생체데이터 파이프라인 전반에 걸쳐 존재하는 극심한 **클래스 불균형(Class Imbalance)** 문제를 해결하기 위해 도입한, 분류 단계(Stage)와 모델(RF/CNN)의 특성에 맞춘 이원화된 샘플링 전략을 기록한 자료입니다.

---

## 1. 문제 인식 (Problem Definition)

우리의 데이터셋은 두 가지 층위에서 전혀 다른 성격의 불균형 문제를 안고 있었습니다.

1. **대분류 (Stage 1: 정상인 vs 환자):**
   - 건강한 대조군(Healthy Control)은 약 10%에 불과한 반면, 환자군(Impaired)이 약 90%를 차지하는 압도적인 편향.
   - 그대로 학습할 경우 모델이 무조건 "환자"라고 찍는(Majority Voting) 현상 발생.

2. **소분류 (Stage 2/3: 환자군 내부 세부 질환):**
   - 발목(Ankle, 627명)과 무릎(Knee, 625명)은 데이터가 풍부한 반면, 고관절(Hip, 450명)이나 발뒤꿈치(Calcaneus, 382명)는 상대적으로 부족.
   - 여기서 데이터를 줄이는 방식을 쓰면, 전체 훈련 데이터가 너무 부족해져서 딥러닝(CNN)이 특징을 학습할 수 없음.

---

## 2. 샘플링 전략의 이원화 (Dual Strategy)

위와 같은 상반된 문제 상황을 타개하기 위해 분류 단계별로 정반대의 샘플링 기법을 적용했습니다.

### 🟢 Stage 1 (정상 vs 환자): `Undersampling` (언더샘플링)
- **전략:** 넘쳐나는 환자 데이터를 정상인 데이터의 수(명수 기준)에 맞춰 깎아냅니다.
- **구현 특징:** 단순 Row 단위 랜덤 픽업이 아닌 **'Subject-level(환자 ID 기준)' 언더샘플링**과 **'Trial Cap(1인당 최대 10보)'**을 도입하여 샘플링 과정에서의 과적합(Overfitting)과 가중치 편향을 완벽히 차단했습니다.

### 🔴 Stage 2 & 3 (세부 질환 분류): `Oversampling` (오버샘플링)
- **전략:** 데이터 총량을 유지하고 신경망의 학습 기회를 보장하기 위해, 부족한 소수 클래스(Hip, Calcaneus)의 데이터를 가상으로 증폭시키거나 가중치를 부여합니다.

---

## 3. 알고리즘 특성별 맞춤형 오버샘플링 구현

소분류 단계에서 무작위로 데이터를 증폭시키는 대신, 앙상블되는 두 모델(Random Forest, 1D-CNN)이 다루는 **데이터의 물리학적 특성**에 맞춰 오버샘플링 기법마저 이원화했습니다.

### 🌳 Random Forest (스칼라 데이터) ➡️ `SMOTE`
- **특성:** Peak 힘, COP 이동 거리 등 1차원적인 스칼라(Scalar) 수치 데이터.
- **적용:** **SMOTE (Synthetic Minority Over-sampling Technique)** 알고리즘을 사용하여, 소수 클래스의 데이터 포인트들 사이를 선형 보간하여 가상의 데이터를 새롭게 합성해 냅니다. 이를 통해 RF가 4개 질환을 정확히 1:1:1:1의 비율로 학습하도록 강제했습니다.
  ```python
  from imblearn.over_sampling import SMOTE
  smote = SMOTE(random_state=42)
  X_train_rf_res, y_train_rf_res = smote.fit_resample(X_train_rf, y_train_rf)
  ```

### 🧠 1D-CNN (시계열 파형 데이터) ➡️ `Class Weights` (가중치 페널티)
- **특성:** 지면반력(vGRF)의 0~100% 진행을 나타내는 연속적인 시계열 파형(Waveform).
- **적용:** 시계열 데이터에 SMOTE를 쓰면 자연스러운 파형이 심각하게 찌그러지거나 노이즈가 발생합니다. 따라서 데이터를 가짜로 복제하는 대신, 딥러닝 로직 상에 **클래스별 가중치(Class Weights)**를 부여했습니다. 
- 데이터가 적은 발뒤꿈치나 고관절을 모델이 틀렸을 때 발생하는 **오차(Loss) 페널티를 훨씬 더 크게 매겨서**, 모델이 소수 클래스를 더욱 민감하게 들여다보도록 우회적인 오버샘플링 효과를 구현했습니다.
