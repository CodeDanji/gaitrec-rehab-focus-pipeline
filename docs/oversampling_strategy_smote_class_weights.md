# 📈 데이터 불균형 해결: 특성 맞춤형 오버샘플링 전략

환자의 질환을 깊게 세분화하여 예측할수록, 특정 소수 질환의 데이터가 급격히 부족해지는 **데이터 불균형(Data Imbalance)** 문제가 발생합니다. 이를 해결하기 위해 우리는 무작정 데이터를 늘리는 대신, **데이터의 물리적 특성에 맞춘 이원화된 오버샘플링 전략**을 채택했습니다.

---

### 1. 🌳 Random Forest (수치형 스칼라 데이터) ➡️ `SMOTE` 가상 합성
* **문제:** Peak 힘, 보폭 등은 1차원적인 단순 수치이므로 증폭이 필요했습니다.
* **해결:** `SMOTE` 알고리즘을 도입하여, 부족한 질환의 수치 데이터들을 선형 보간(Interpolation)해 가짜 데이터를 만들어 훈련 비율의 균형을 맞췄습니다.
  ```python
  from imblearn.over_sampling import SMOTE
  smote = SMOTE(random_state=42)
  X_train_res, y_train_res = smote.fit_resample(X_train, y_train)
  ```

### 2. 🧠 1D-CNN (연속형 시계열 파형 데이터) ➡️ `Class Weights` 페널티
* **문제:** 발이 땅에 닿아있는 동안의 연속적인 힘의 변화(Waveform)에 SMOTE를 적용하면, 파형이 부자연스럽게 찌그러지거나 생체역학적으로 불가능한 노이즈가 발생합니다.
* **해결:** 데이터를 억지로 합성하는 것을 포기하고, 딥러닝 로직 상에 **클래스별 가중치(Class Weights)**를 부여했습니다. 즉, 데이터가 적은 질환을 모델이 틀렸을 때 가하는 **오차(Loss) 페널티를 훨씬 크게 매겨서**, 모델이 부족한 데이터의 패턴을 더 민감하게 학습하도록 우회적인 오버샘플링 효과를 냈습니다.

---

### 💡 핵심 요약 (Key Takeaway)
**"파형 데이터를 억지로 합성하면 생체 데이터의 무결성이 훼손된다."**
단순한 라이브러리(SMOTE) 맹신에서 벗어나, 독립된 수치(RF)에는 **데이터 합성**을, 연속된 파형(CNN)에는 **알고리즘 페널티**를 분리 적용하여 모델 편향을 막아낸 스마트한 엔지니어링 전략입니다.
