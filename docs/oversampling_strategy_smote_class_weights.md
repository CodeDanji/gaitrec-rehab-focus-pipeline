# 📈 소수 클래스 불균형 해결: 알고리즘 맞춤형 오버샘플링 전략

본 문서는 GaitRec 생체데이터 파이프라인 중 **환자군 세부 질환 분류(Stage 2 & 3)** 과정에서 발생한 데이터 불균형 문제를 해결하기 위해 도입된 오버샘플링(Oversampling) 및 가중치(Class Weights) 전략을 별도로 발췌하여 정리한 문서입니다.

---

## 1. 도입 배경 (Background)

환자와 정상인을 구분하는 1단계 분류 후, 환자군(Impaired) 내부에서 4가지 주요 질환을 분류하는 단계에서 다음과 같은 데이터 불균형이 발견되었습니다.
* **다수 클래스:** 발목(Ankle, 627명), 무릎(Knee, 625명)
* **소수 클래스:** 고관절(Hip, 450명), 발뒤꿈치(Calcaneus, 382명)

이러한 불균형 상태로 모델을 학습시킬 경우, AI가 판단이 애매할 때 확률적으로 데이터가 많은 '발목/무릎'으로 예측해버리는 편향(Bias) 문제가 발생합니다. 전체 데이터 수가 많지 않은 상황이므로 데이터를 깎아내는 언더샘플링 대신, **소수 클래스를 보강하는 오버샘플링 방향**으로 논의가 진행되었습니다.

---

## 2. 데이터 물리학적 특성에 따른 맞춤형 전략

단일 오버샘플링 기법을 일괄 적용하지 않고, 앙상블을 이루는 두 가지 모델(Random Forest, 1D-CNN)이 다루는 데이터의 생태계에 맞춰 기법을 철저히 이원화했습니다.

### 🌳 1. Random Forest (스칼라 데이터) ➡️ `SMOTE` 합성
* **데이터 특성:** Peak 지면반력, COP의 이동 거리(Range) 등 1차원적인 스칼라(Scalar) 수치.
* **적용 기법:** 수치 데이터는 물리적인 흐름이 없기 때문에 데이터 포인트 사이를 수학적으로 보간(Interpolation)하여 가짜 데이터를 만드는 것이 유효합니다.
* **구현 방법:** `imblearn`의 **SMOTE (Synthetic Minority Over-sampling Technique)** 알고리즘을 도입하여, 소수 질환(Hip, Calcaneus)의 가상 데이터를 증폭시켜 4개 질환이 1:1:1:1로 학습되도록 강제했습니다.
  ```python
  from imblearn.over_sampling import SMOTE
  
  # SMOTE를 통해 소수 클래스의 스칼라 피처 증폭
  smote = SMOTE(random_state=42)
  X_train_rf_res, y_train_rf_res = smote.fit_resample(X_train_rf, y_train_rf)
  ```

### 🧠 2. 1D-CNN (시계열 파형 데이터) ➡️ `Class Weights` 페널티
* **데이터 특성:** 지면반력(vGRF)의 발구름 0~100% 진행 구간을 나타내는 끊어지지 않는 연속적 시계열 파형(Waveform).
* **적용 기법:** **파형 데이터에 SMOTE를 적용하면 파형이 부자연스럽게 찌그러지거나 생체역학적으로 불가능한 노이즈가 낄 위험성**이 매우 높습니다. 따라서 가짜 데이터를 물리적으로 합성하는 것을 금지했습니다.
* **구현 방법:** 파형 데이터 원본은 그대로 두되, 딥러닝(CNN)의 손실 함수(Loss Function)에 **클래스 가중치(Class Weights)**를 부여했습니다. 즉, 모델이 소수 클래스(발뒤꿈치 등)를 틀렸을 때 가하는 페널티를 훨씬 더 크게 매겨, 적은 데이터만으로도 민감하게 특징을 잡아내도록 '우회적인 오버샘플링 효과'를 달성했습니다.

---

## 3. 엔지니어링 결론 (Conclusion)

이 전략은 데이터 분석 시 흔히 저지르는 **'무지성 SMOTE 적용'**의 오류를 완벽하게 피해 간 사례입니다.
데이터 증강(Data Augmentation)을 수행할 때 데이터 고유의 물리적 특성(독립된 수치인지 vs 연속된 파형인지)을 명확히 이해하고, 이에 맞춰 **데이터 합성(SMOTE)과 알고리즘 페널티(Class Weights)를 분리 적용**함으로써 생체 데이터의 도메인 무결성을 지켜낸 정교한 엔지니어링 프로세스입니다.
