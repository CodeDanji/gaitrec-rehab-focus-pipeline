# 📈 가중치 기반 계층적 앙상블(Weighted Hierarchical Ensemble) 최적화 과정

본 문서는 기존 5:5 비율의 단순 앙상블에서 벗어나, 생체역학적 도메인 지식(Domain Knowledge)을 결합하여 각 관절 부위별로 머신러닝(RF)과 딥러닝(CNN)의 개입 비율을 최적화한 과정의 흐름(Flow)을 기록한 자료입니다.

---

## 1. 문제 인식 (Problem Definition)
- 기존의 계층적 모델(Hierarchical Model)은 상체/하체를 1차로 구분하고, 2차로 세부 관절을 구분하는 트리(Tree) 구조를 채택하여 클래스 불균형 문제를 완화했습니다.
- 그러나 모든 분류 단계에서 **Random Forest(스칼라 데이터)와 1D-CNN(시계열 파형 데이터)의 예측 확률을 단순히 5:5로 평균(Soft Voting)** 내고 있어, 각 관절 부위별 생체역학적 특성을 모델 구조에 반영하지 못하는 한계가 있었습니다.

---

## 2. 가설 수립 (Hypothesis Generation)
사용자(연구자)의 직관적인 제안에 따라 다음과 같은 도메인 지식 기반의 가설을 수립했습니다.

1. **Upper(고관절/무릎) 모델:**
   - 보폭, COP(압력 중심)의 앞뒤/좌우 흔들림 등 **거시적인 스칼라(Scalar) 수치**가 분류에 결정적인 역할을 할 것이다.
   - ➡️ **전략:** Random Forest의 가중치를 대폭 늘린다. (RF 8 : CNN 2)

2. **Lower(발목/뒤꿈치) 모델:**
   - 발을 딛는 순간의 충격 회피 패턴, 국소적인 지면반력(vGRF) 파형의 찌그러짐 등 **미시적인 파형 데이터**가 분류에 더 중요할 것이다.
   - ➡️ **전략:** 1D-CNN의 가중치를 대폭 늘린다. (RF 2 : CNN 8)

---

## 3. 1차 실험 및 검증 (First Experiment & Analysis)

### 🟢 Upper 모델 (Hip vs Knee) - 가설 적중
- **설정:** RF 0.8 : CNN 0.2
- **결과:** 기존 약 61.0%에 머물던 정답률(Macro F1)이 **62.8%**로 뚜렷하게 상승.
- **분석:** 상체 관절 분류 시 파형 노이즈의 개입을 줄이고 거시적 수치에 집중하게 한 전략이 완벽하게 적중함.

### 🔴 Lower 모델 (Ankle vs Calcaneus) - 의외의 발견
- **설정:** RF 0.2 : CNN 0.8
- **결과:** 기존 약 70.0% 였던 정답률이 오히려 **66.0%**로 하락.
- **분석:** 하체의 경우 파형의 형태(CNN)가 중요하긴 하나, '순간적인 최대 충격량(Peak)'과 'COP 범위' 같은 직관적인 스칼라 데이터(RF)를 20%로 너무 과도하게 무시한 것이 성능 저하의 원인으로 밝혀짐.

---

## 4. 2차 실험 및 최적화 (Optimization)

### 🔥 Lower 모델 가중치 재조정 (RF 7 : CNN 3)
- **설정 변경:** 1차 실험의 피드백을 반영하여, 하체 모델에서도 뼈대가 되는 스칼라 수치(RF)의 비중을 다시 70%로 올리고 파형(CNN)은 30%의 디테일을 보완하는 구조로 수정.
- **결과:** 정답률(Macro F1)이 **70.81%**로 폭등하며, **프로젝트 진행 이래 하체 소분류 기준 역대 최고점**을 경신!

---

## 5. 최종 결론 (Final Architecture & Conclusion)

이상의 최적화 과정을 거쳐, 파이프라인의 최종 계층적 앙상블 비율은 다음과 같이 확정되었습니다.

| 분류 단계 (Stage) | 타겟 (Target) | 앙상블 가중치 (RF : CNN) | 비고 |
| :--- | :--- | :---: | :--- |
| **Stage 1** | Upper vs Lower | `5 : 5` | 대분류는 양쪽 데이터의 특징을 균형있게 반영 (F1: ~76%) |
| **Stage 2** | Hip vs Knee | `8 : 2` | 거시적 흔들림, 보폭 수치가 중요 (F1: 62.8%) |
| **Stage 3** | Ankle vs Calcaneus | `7 : 3` | 스칼라 수치가 뼈대를 잡고, 파형이 디테일을 보완 (F1: 70.8%) |

**💡 엔지니어링 의의:**
단순한 AI 모델의 조합(Ensemble)을 넘어, **데이터가 가진 생체역학적 의미를 모델의 가중치로 직접 치환(Translation)**하여 한계를 돌파한 모범적인 머신러닝 최적화 사례입니다.
